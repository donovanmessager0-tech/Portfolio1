Mes Langages

HTML
HTML (HyperText Markup Language) est un langage de balisage utilisé pour structurer et représenter le contenu des pages web. Il permet d'organiser le texte, les images, les vidéos et d'autres éléments en utilisant des balises spécifiques.
CSS
Le CSS (Cascading Style Sheets) est un langage utilisé pour décrire la présentation visuelle d’un document HTML. Il permet de séparer le contenu (HTML) de la mise en forme, en définissant des règles qui contrôlent l’apparence des éléments.
JS
JavaScript (JS) est un langage de programmation léger et dynamique utilisé principalement pour rendre les pages web interactives et dynamiques. Il permet d'implémenter des mécanismes complexes sur une page web, tels que des animations, des mises à jour de contenu en temps réel, et des interactions utilisateur
GIT
Git est un système de contrôle de version distribué, libre et open source, permettant de suivre et gérer les modifications apportées à un projet logiciel.
PHP
PHP est un langage de script côté serveur, principalement utilisé pour créer des sites web dynamiques et interactifs.
C
Le C est un langage puissant, rapide et proche de la machine, utilisé pour développer des systèmes, des logiciels critiques et des applications nécessitant un haut niveau de performance.
C#
C# est un langage de programmation orienté objet moderne, développé par Microsoft pour la plateforme .NET, utilisé pour créer des applications variées allant des logiciels Windows aux jeux vidéo.
SQL
SQL (Structured Query Language) est un langage de programmation standardisé utilisé pour manipuler et interagir avec des bases de données relationnelles.
Python
Python est un langage de programmation interprété, polyvalent et facile à apprendre, utilisé pour automatiser des tâches, développer des applications et analyser des données.

Mes Outils

WAMP
WampServer est une plate-forme de développement Web sous Windows pour des applications Web dynamiques à l’aide du serveur Apache2, du langage de scripts PHP et d’une base de données MySQL. Il possède également PHPMyAdmin pour gérer plus facilement les bases de données.
Visual studio
Visual Studio est un ensemble complet d'outils de développement permettant de générer des applications web ASP.NET, des services web XML, des applications bureautiques et des applications mobiles.
Phpstorm
PhpStorm est un IDE puissant pour PHP, HTML, CSS et JavaScript, offrant autocomplétion, gestion de bases de données et intégration avec Docker et Vagrant pour simplifier le développement web.
Clion
CLion offers a complete coding experience that lets you develop in C and C++ quickly and safely without juggling external tools.
Github
GitHub est un service web d'hébergement et de gestion de développement de logiciels, utilisant le logiciel de gestion de versions Git.
Local
LocalWP is a free, user-friendly tool that allows you to develop, test, and manage WordPress sites locally on your computer before publishing them online.
